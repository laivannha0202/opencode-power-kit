# OpenCode Power Kit v2.3.0

Release date: 2026-08-17

## Highlights

- Adds `opk-main` as the lightweight primary agent/router while keeping
  specialist and `build-strong` delegation bounded.
- Hardens secret protection across OpenCode permissions, the token guard,
  shell guard, nested `ssh`/`eval` destructive-command detection, and
  unattended `opk auto` runtime preflight.
- Installs and verifies the reviewed safety guard, token guard, and
  `opk-main` runtime assets for project/global workflows.
- Advances reviewed upstream compatibility to Superpowers `v6.3.0` and
  BMAD Method `v6.11.0`.
- Adds BMAD 6.11 runtime prerequisite checks for Node `>=20.12.0`, `npx`,
  `uv`, and `python3` without auto-installing system runtimes.
- Fixes release validation so `detect-mode.py` is recognized as delegating
  JSON/JSONC parsing to the shared `opk_mode.load_config` implementation.

## Safety and compatibility

- Linux-only distribution remains unchanged.
- Existing custom OpenCode model/provider/MCP/plugin/formatter/LSP keys are
  preserved by project merge behavior.
- Destructive operations remain fail-closed.
- No automatic commit, push, tag, release, or system-runtime installation is
  introduced by this release.

## Validation

Release preparation requires the complete local release gate, workflow evals,
installer preservation tests, resolved OpenCode config tests, transaction/WAL
tests, guard tests, `verify.sh`, `doctor.sh --deep`, integration tests, and
`git diff --check` to pass with zero warnings.

GitHub Actions is an independent publication prerequisite. A green local gate
does not override a GitHub Actions job that failed to start.

## Upstreams

- Superpowers: `v6.3.0`
- BMAD Method: `v6.11.0`
